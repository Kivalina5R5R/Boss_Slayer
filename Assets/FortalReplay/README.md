# Fortal Replay Signal 1.0 (Unity)

สำหรับทีมที่ทำเกม Main Arena · ทำ 2026-11-25

ใส่ asset นี้แล้วเรียก 2 คำสั่ง เกมของคุณจะถูกอัดและตัดเป็นคลิปไฮไลต์ให้ลูกค้าโดยอัตโนมัติ

## ต้องทำอะไร

1. Import `FortalReplaySignal.unitypackage` (Assets > Import Package > Custom Package) จะได้โฟลเดอร์ `Assets/FortalReplay`
2. เรียก 2 คำสั่งนี้ในโค้ดของเกม

```csharp
using FortalReplay;

// ตอนผู้เล่นเริ่มเล่นได้จริง (หลังเมนูและ countdown)
ReplaySignal.GameStarted("MyGame", playerCount);

// ตอนขึ้นหน้าผล
ReplaySignal.GameEnded(scores);
```

แค่นี้พอ ไม่ต้องวาง GameObject ในซีน ไม่ต้องตั้งค่า ไม่ใช้เครือข่าย

## คำสั่งทั้งหมด

| คำสั่ง | เรียกเมื่อ | บังคับ |
|---|---|---|
| `ReplaySignal.GameStarted(game, playerCount)` | ผู้เล่นเริ่มเล่นได้จริง | ใช่ |
| `ReplaySignal.GameEnded(scores, winners)` | ขึ้นหน้าผล | ใช่ |
| `ReplaySignal.Moment(name, player)` | มีจังหวะเด็ดเกิดขึ้น เช่น ล้มบอส, คอมโบ, พลิกชนะ | ไม่ |
| `ReplaySignal.GameAborted()` | รอบถูกยกเลิกกลางคัน (กด Exit, ผู้เล่นออกหมด) | ถ้ามีกรณีนี้ |

- `game`: ชื่อเกม ใช้ชื่อเดิมทุกครั้ง เพราะคลิปถูกเก็บแยกตามชื่อนี้ เก็บเฉพาะ a-z, 0-9, `_`, `-` (ช่องว่างและภาษาไทยถูกตัดออก)
- `scores`: คะแนนของแต่ละคน ตำแหน่ง 0 = ผู้เล่นคนที่ 1 ใส่ `null` ได้ถ้าเกมไม่มีคะแนน
- `winners`: ตำแหน่งของผู้ชนะ เว้นว่างได้
- `Moment`: ยิ่งส่งจังหวะสำคัญมา คลิปไฮไลต์ยิ่งตรงจุด ถ้าไม่ส่งเลย ระบบจะเลือกช็อตจากช่วงที่ภาพขยับมากที่สุด

## เรียกตรงไหนถึงจะถูก

- `GameStarted` เรียกตอนเกมเริ่มจริง ไม่ใช่ตอนเปิดเมนู ไม่อย่างนั้นคลิปจะมีช่วงรอคนและ countdown ติดมา
- `GameEnded` เรียกตอนหน้าผลขึ้น ตัวอัดจะอัดต่ออีกราว 4 วินาทีแล้วหยุดเอง หน้าผลจึงอยู่ในคลิป
- เกมที่มีหลายด่านในรอบเดียว ให้เรียก `GameStarted` ครั้งเดียวตอนเริ่ม และ `GameEnded` ครั้งเดียวตอนจบ ไม่ต้องเรียกทุกด่าน

## สิ่งที่ asset จัดการให้แล้ว

- เรียก `GameStarted` ซ้ำ: รอบเก่าถูกปิด แล้วเริ่มรอบใหม่
- เรียก `GameEnded` ตอนไม่มีรอบ: ไม่เกิดอะไร
- ปิดเกมกลางรอบ: รอบถูกปิดให้เอง
- ลืมเรียก `GameEnded`: รอบถูกปิดเองหลัง 30 นาที (แก้ได้ที่ `ReplaySignal.MaxMinutes`)
- ทุกคำสั่งไม่ throw error เข้าเกม ถ้าเขียนไฟล์ไม่ได้ จะมีแค่ warning ใน Console

## ข้อควรรู้

- รอบที่สั้นกว่า 20 วินาทีจะไม่ถูกตัดเป็นคลิป (ตัวอัดถือว่าเป็นการกดผิด)
- บนเครื่องที่ไม่ได้ลงตัวอัด (เช่นเครื่อง dev) asset แค่เขียนไฟล์เล็ก ๆ ลงโฟลเดอร์ `ReplayLogs` ไม่มีผลอื่น
- ใน Editor ไฟล์จะอยู่ที่ `<โปรเจกต์>/ReplayLogs` ควรเพิ่มโฟลเดอร์นี้ใน `.gitignore`
- ใน build ไฟล์จะอยู่ที่ `<โฟลเดอร์เกม>/ReplayLogs` ข้างไฟล์ `.exe` ตัวอัดของ Main Arena เฝ้าโฟลเดอร์นี้อยู่ จึง**ห้ามเปลี่ยน** `ReplayLog.OutputDirectory`

## ทดสอบว่าใส่ถูก

ใน Editor:

1. วาง `Example/ReplaySignalExample.cs` บน object ใดก็ได้ แล้วกด Play
2. คลิกขวาที่ชื่อ component เลือก "Test: start a round" รอสักครู่ แล้วเลือก "Test: end the round"
3. Console ต้องขึ้น `[Replay] ▶ ... session started` และ `[Replay] ■ ... session completed`
4. โฟลเดอร์ `<โปรเจกต์>/ReplayLogs` ต้องมีไฟล์ `_live.json` ที่ข้างในมี `"state":"ended"` และไฟล์ `<ชื่อเกม>_<วันเวลา>.jsonl`

บนเครื่อง Main Arena จริง: เล่นหนึ่งรอบ (เกิน 20 วินาที) แล้วดูหน้า status ของ Replay Hub การ์ดของเครื่องจะขึ้น "กำลังเล่น <ชื่อเกม>" ระหว่างรอบ และมีคลิปใหม่ในคลังหลังจบรอบราว 1 ถึง 2 นาที

## ถ้าอยากให้ไฮไลต์ฉลาดขึ้นอีก (ไม่บังคับ)

`ReplayLog.cs` ในโฟลเดอร์เดียวกันมีคำสั่งละเอียดกว่า เช่น `ReplayLog.WriteFrame(...)` สำหรับส่งตำแหน่งและคะแนนของผู้เล่นทุก 0.1 วินาที ระบบใช้ข้อมูลนี้หาจังหวะสูสีและจังหวะพลิกเกมได้เอง ดูวิธีใช้ในคอมเมนต์ของไฟล์

## ไฟล์ใน asset
